## 固定模型输出前端与共同计分契约

将模型输出接口和计分中间坐标明确分开：

1. 7B保持已完成并冻结的处理器像素接口，结果不再重跑。
2. 9B所有N/A1/A2/U、全部seed使用**同一个明确0–1000提示与解析器**。
3. 9B原生框先换成实际编码图像的处理器像素：`x_proc=x_native×W_proc/1000`，`y_proc=y_native×H_proc/1000`。
4. 使用共同映射回原图：`x_orig=x_proc×W_orig/W_proc`，`y_orig=y_proc×H_orig/H_proc`；与原图GT计算IoU≥0.5。

这是对v3“所有模型原始文本直接给处理器像素”要求的明确修订，不追溯宣称v3已通过。两阶段转换与`x_native×W_orig/1000`代数等价；共同中间坐标并不证明两个模型家族所有测量混杂均被消除。

原始文本、原生千分比框、处理器框、原图框、处理器网格、EOS/长度停止原因均应保存。语法统一接受严格JSON框及严格四数CSV；不从说明文字抽框，不按坐标大小、臂、GT或IoU切换单位，不修正非法框，不更换模型或量化精度。

## 一次性校准预算与停止规则

最多N×100条+15适配器×20条=400个新定位预测、独立900秒GPU墙钟上限（包含模型装载），2.70元/小时下活动时间上限约0.675元，不含注册/等待。此预算已在新v4目录启动并保存绝对起止时间，重启不能重置，也不修改v3已经失败的预算。只固定一个提示版本，不追加变体寻找80%成绩。

N先跑：定位准确率≥80%，解析失败≤5/100；不满足即停止，不能拿旧86%诊断放行。全部16模型还须检查无长度截断、框单位和网格记录完整、损失/恢复工程证据可追溯、无优化器和梯度、reserved≤30GB、磁盘空闲≥5GiB、原始输出与独立重评分一致。每适配器20条的解析失败≤1/20；此样本只作接口工程检查，不能据其推断能力高低或显著性。

若训练臂得分较低，不据此换单位、改提示或剔除该臂；必须将其解释边界限定为该固定指令下的定位与格式遵循联合表现。若契约遵循证据不足，则不作纯定位能力结论。遇到OOM、非有限值、SHA不符、预算耗尽或准入失败立即停止；只有明确瞬时网络传输故障可按有界规则重试。
