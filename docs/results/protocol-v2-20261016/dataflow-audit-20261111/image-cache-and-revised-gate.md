# 数据流审计：图像近重复、7B 教师缓存与修订 C

更新：2026-11-12（北京时间）。只用 CPU，沿用原始冻结数据，不改历史报告、训练配置或准入门槛。

## 图像隔离与近重复敏感性

用候选索引归档中的历史图像指纹补齐了 2,132 个训练图像路径。训练侧及五组评测侧的指纹记录全部与恢复映射中的原文件 SHA256、大小对齐。按不同 RGB SHA 去重后，对每组重新计算训练到评测的 64 位 dHash 汉明距离。dHash≤4 只作人工复核候选；同一个 dHash 不证明像素、语义或来源相同。本轮复算使用已存解码指纹，没有声称重新解码所有原图。

| 评测组 | 图像路径 | 训练–评测相同 RGB | dHash≤4 候选对 |
|---|---:|---:|---:|
| 校准 | 381 | 0 | 9 |
| 审计 | 2,677 | 0 | 0 |
| 确认候选 | 2,646 | 0 | 0 |
| 历史 v4.1 正式集 | 4,705 | 0 | 724 |
| 9B 2×2 旧保留集 | 426 | 0 | 0 |

详见[逐对候选及计数](image-and-7b-cache-replay.json)。历史候选集中在推理和一致性轴；尚未逐对目视核实，不能当作已证实的数据泄漏。采用最保守的诊断：将命中任一候选的所有评测图像连同 RGB 别名排除，固定所有模型的排除集合，依旧按同图像簇与配对 seed 重抽样。排除 POPE 18、一致性 50、MMStar 138 个原题，**没有排除任何定位原题**。9B 登记 12 项校正区间的过零判断均未改变；A1−N 一致性变为 **+5.09 pp，校正区间约 [0.09, 9.60] pp**，说明该证据对样本选择有一定敏感性。定位 U137 42.58% 不受这批候选影响。完整数值见[敏感性凭证](near-image-sensitivity.json)，此分析不替代原正式全量结果。

参照[Open Images 的跨库重叠表](https://storage.googleapis.com/openimages/web/2022-06-21-overlaps-with-coco-and-flickr30k.html)，下一轮的清洗应保留候选列表、判定依据与分母；独立确认集只允许在看新结果前依规则冻结。零 dHash 候选不排除裁剪或语义近重复，不等同于预训练无污染。

## 7B 重新生成的教师缓存

从约 9.85 MB 的正式 BF16 EOS 缓存归档实际加载 **3,545/3,545 条** PyTorch 样本（CPU，`weights_only=True`）。每条 SHA256 同时与缓存完成清单和最终恢复映射匹配；题 ID、训练图片 SHA、目标和输入尾部对齐，top-50 indices/logits 均为每目标 token 对应 50 项，logits 与归一化项有限，top-50 概率质量不超过 1 加浮点容差。

所有原始生成的最后一个 token 都是 **151645**；最长定位生成 **72 token**，其余轴最多 3，均未达到 128 的长度上限。EOS 白名单来自 [Qwen2.5-VL-7B 冻结 revision 生成配置](https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct/blob/cc594898137f460bfe9f0759e9844b3ce807cfb5/generation_config.json)，实际取回副本见[固定配置](qwen7b-pinned-generation-config.json)。以上是 7B 独立实验的新 BF16 教师缓存，**不外推至原 v1 旧缓存**；旧缓存缺原始生成 token 与终止原因，仅靠重新编码的末尾 EOS 无法证明未截断。

Qwen 的严格反转点估计两种均为 0，且达不到至少 95% 有效外层差值门槛。详见[六项重算](revised-gate-replay.json)。因此原 ARP 修订主线仍不具备训练准入，独立蒸馏结果不能替代这个门槛。
