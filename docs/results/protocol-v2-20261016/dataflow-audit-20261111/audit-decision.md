# 实验与数据流审计：结论及续跑前准入清单

更新：2026-11-12（北京时间）。审计的是已有实验的数据、程序和主张；未启动确认实验，也未改变任何历史端点或结果。

## 原 v1 的教师缓存与 D 实际训练

[旧缓存与 D 训练核验](v1-teacher-and-training-replay.json)实际取回并在 CPU 加载了原 v1 的 **3,545 条** top-50 样本。逐一校验原始训练图片 SHA、训练样本 ID、token 词表、目标与输入尾部、有限 logits、top-50 维度及概率质量。所有保存的重编码训练目标末尾为 token 198；缓存没有保存原始生成 ID 或 finish_reason，不能据此判断模型生成 EOS 或未截断。与之分开的 7B BF16 新缓存才有逐条原始 EOS 证据。

原 D 的三臂注册清单按历史 Qwen 排名和原池重建后，与原始 SHA 完全相同；3,000 步实际样本次序与种子重排结果逐条一致，N 无更新。A1 为 ScienceQA 代理，A2 为一致性。U 的注册池每轴 600 条，但全局打乱后取前 1,000 步，实际 POPE、定位、一致性、推理代理分别为 **249、241、253、257**；原论文应说「等比例注册池」，不应将后来实验的每轴 250 步写回旧 D。日志记录的 AMP 重试为 A1/A2/U 分别 5/3/5，检查基于实际步号而非尝试次数。

原 D 的 CE 来自缓存教师文本，同时对同一输出轨迹做 top-50 加尾桶 KL；7B/9B 独立方案使用 GT CE 加教师文本 CE，7B 独立方案虽存有 top-50 也未用其 KL。三条实验线不能当作同一个蒸馏配方比较。[旧缓存与 D 核验脚本](../../../../tools/audit_archived_v1_teacher_and_training.py)。

## 哪些结论经得住当前审计

| 主张 | 当前判断与证据 |
|---|---|
| 原 ARP 量尺敏感性可据此放行 | **不能。** [v1 重算](v1-replay.json)复现历史判定；[修订 C 六项复算](revised-gate-replay.json)均不确定。同检查点 API 桥接也未放行。 |
| 7B 的定位排名代表稳健的训练能力差异 | **不能。** [固定输出交叉计分](7b-historical-replay.json)单换评分就使 A1−U 从 −11.53 到 +11.77 pp；[处理器像素正式复测](7b-and-roles-replay.json)的 +3.32 pp 是新的推理与评分契约。 |
| 9B U137 的 42.58% 是解析错误、截断或训练未完成 | **现有实证不支持。** [正式逐题复算](v41-replay.json)只有 3 条定位解析失败、零定位截断；[30 次训练账本](training-chain-replay.json)与固定步数和采样对齐。候选近重复排除没有移除任何定位题。尚不能确定退化的单一机制。 |
| 归一化目标本身带来约 22 pp 的提升 | **不能单独归因。** [2×2 复算](factorial-replay.json)复现 24 项效应；真实操作同时改动提示（+35 tokens）和目标序列（GT 平均约 +25 tokens），只有两个 seed，且正式评测使用统一归一化提示。 |
| 9B 的 A1 一致性收益普遍稳健 | **证据有限。** 全量登记区间排除零，但[移除跨图复用题面](prompt-reuse-replay.json)后区间跨零。A1 未训练 MMBench；不能将这种敏感性等同于 A1 直接记忆。 |
| 六个 9B 补训练端点与实际评测有完整来源 | **账本与哈希可证。** [六端点复算](factorial-training-replay-all.json)对齐 6,000 步及两份评测元数据；本轮未重新加载全部优化器/适配器张量，不把元数据核验称为训练复现。 |

公开工作的映射与链接见[总入口](README.md)、[图像去重方法](training-and-statistics.md)和[标注与选项敏感性](annotation-and-prompt-reuse.md)。它们支持采用明确坐标输出、分来源汇总、同图聚类及带图/无图与选项重映射对照；不为本项目提供可直接混用的分数。

## 给下一轮的冻结前检查

1. **数据**：原始文件版本、图像/题面/选项组合身份、精确 RGB 和近重复候选、历史训练与推理曝光、每轴有效图像簇数。明确题面相同但图像不同的处理规则；不得看到新结果后筛题。公开数据预训练污染无法仅靠项目内档案排除。
2. **干预**：明确两种对称训练契约与冻结的标签量化精度，输出格式一致，报告输入和目标 token 长度。记录每 seed 两臂相同样本、初始状态与步序。旧 2×2 不能当作只改标签的直接复现。
3. **评测**：每端点在两种冻结推理口径交叉评测，固定解析器、EOS、IoU 阈值和无效输出政策；同图像簇包含所有精确别名。主分析仍为同一归一化部署口径；像素提示、分来源、解析率、选项轮换和无图作为预登记的解释性分析。未完成盲审前不把新集称作经盲审的独立确认集。
4. **运行与统计**：冻结主对比、实用阈值、预算、配对种子、失败与缺失处置，再做资源预检。7B 现有 EOS 缓存、9B 文本教师缓存和 v1 缓存的保证范围不同，分别标记；若只做 GT-only，不再请求 API。原 ARP 修订 C 未过，不与独立的 9B 续实验混用。

当前不建议先租卡。可先从确认候选中冻结新样本并安排独立盲审，同时核查受限制的源数据和历史近重复候选；归档复算没有替代这些新数据准入步骤。
