# 数据流审计：训练来源、原 B/C/D 与统计复算

更新：2026-11-12（北京时间）。

## 原实验与正式训练

- [v1 重算凭证](v1-replay.json)：从归档重读 **7 个基础模型共 118,300 条**原始输出，按原始分层汇总口径复现四轴表；从 A1/A2/U 的 **50,700 条**训练后原始输出重做计分，复现四臂带符号收益及 Table 4，N 复用基础模型。使用已核验 SHA 的历史分层清单和基线分数，重新生成 C 的每个模型族 1,000 组配对 score/floor 重采样，对齐三套 120 设置及经验等价类（Qwen 9、Intern 54、LLaVA 10）。历史 F_scale/F_noise 区间由已保存 draws 重算；未重新生成全部内外层 F/noise draws。历史 gate 的 go 与修订版的未放行不是同一判定，当前复算不改变后者。
- [30 次训练链路凭证](training-chain-replay.json)：7B 和 9B 的 30,000 步均逐步核对。每次 600 个唯一提示按归档次序循环，1,000 个连续实际更新，梯度为正且各项损失有限，双 CE 数值对齐。U 的四轴各 250 步，A1/A2 的轴与登记一致。所有适配器 SHA 都能对齐恢复映射；9B 的恢复状态亦能逐一对齐完成标记。7B 的恢复状态在映射内，但同一完成标记没有记录其 SHA。此次核对的是来源和账本，并未重载所有权重或优化器张量。

## 图像隔离：可证范围与剩余风险

将原 3,545 条训练池及 9B 可用 3,540 条训练池，与四份冻结评测输入一起连接到已核验的恢复映射。原池有 **2,132 个图像路径、2,093 个唯一字节哈希**，可用池有 2,131 个路径、2,092 个哈希。校准、审计、确认和历史 v4.1 正式评测的每个引用路径都能查到 SHA256；两版训练池与这些评测集的同路径、同字节 SHA256 和可从 COCO 文件名提取的规范 ID 交集均为零。该检查补上第一批仅有评测角色索引的缺口，但尚未解码训练图像重新核对 RGB 哈希和近重复，不能排除跨编码、缩放、裁剪或其他数据源别名。

这个顺序与 [MMDetection 的 MM-Grounding-DINO 数据准备](https://github.com/open-mmlab/mmdetection/blob/main/configs/mm_grounding_dino/dataset_prepare.md)一致：不能把 COCO 与 RefCOCO 的数据集名称当成独立性保证。可借鉴 [Open Images 的跨库重叠登记](https://storage.googleapis.com/openimages/web/2022-06-21-overlaps-with-coco-and-flickr30k.html)，保留训练→评测重叠对和分母；新实验若有重叠，优先按冻结规则移除训练侧污染，保留原评测集与历史分数。参考 [DataComp](https://arxiv.org/abs/2304.14108) 的控制方式，先固定训练算法与评测，只变更待审查的数据处理策略。

## 122B 教师：完整覆盖不等于目标全对

全部 **3,540 条**缓存教师记录与可用池逐一匹配：唯一题 ID、请求 ID、轴、图像路径和源图 SHA 一致，返回模型名及 API stop 状态一致。被排除的是一致性轴 5 条、对应一个训练图像。缓存不提供内部教师 token 或 EOS；学生 tokenizer 追加 EOS 是另一个步骤，不能混称。传图大小和 PNG SHA 在缓存中有记录，本轮未重新编码重建请求体。

| 训练轴 | 条数 | 严格协议下与 GT 一致 | 审计说明 |
|---|---:|---:|---|
| POPE | 600 | 579 | 严格解析失败 0 |
| 定位 | 600 | 553 | 原生框映射回原图后 IoU≥0.5；中位 IoU 0.9373，47 条低于阈值 |
| 一致性 | 1,740 | 1,637 | 按提示计，严格解析失败 5 |
| 推理代理 | 600 | 588 | 严格解析失败 6 |

600 条定位的教师请求提示都不同于训练池提示：教师以归一化坐标回答，9B 历史学生训练将教师坐标转换为原图像素并保留三位小数。非定位直接使用教师文本；严格解析失败不等于文本一定错误，但这部分会让学生训练目标与部署格式有差异。新 GT-only 确认实验不应为教师失败或命中情况临时筛样本；若之后做教师增量比较，需登记过滤策略、保留未过滤对照并报告每轴保留率。

## 统计复算揭示的 MMStar 簇问题

从冻结逐题表按登记种子、同一图像簇权重和配对 seed 重新生成 10,000 次抽样，**复现 9B 的 12 项以及 7B 定位的 4 项区间**。随后对 9B 另做诊断：同轴中若图像字节 SHA 一致，传递合并其簇；不改题目分数或分母。MMStar 有 61 个哈希被分入多个簇，合并后 **1,500 原题对应 1,430 个簇**；另外三轴在此检查中簇数未变。三条 MMStar 校正区间依旧跨零，例如 A1−N 从约 **[−2.78, +9.88] pp** 变为 **[−2.98, +9.75] pp**。这项敏感性不推翻原结论，但后续协议应在抽样前合并图像别名，不能把 1,500 道题写成 1,500 张独立图像。

## 9B 定位 2×2：实际干预与 24 项效应

[原始输出与冻结输入复算](factorial-replay.json)覆盖开发集 152,100 条（含从 v4.1 复用的三个端点）和旧保留集 8,640 条。全部从原始文本重评；24 项坐标、教师和交互效应及其校正区间均复现。定位的坐标主效应在开发集为 **+22.75 pp [9.99, 36.07]**，在旧保留集为 **+21.875 pp [5.33, 40.85]**；只有两个训练 seed，不能当作独立确认。保留集 426 个图像路径与可用训练池、历史开发集都没有同路径、同文件 SHA 或可解析 COCO ID 交集。

从分卷前段实际取回了全部 8 份注册训练输入，并用恢复映射验证其与实际训练输入文件的 SHA 相同。每个 seed 的四份输入与旧 U 端点采样顺序一致，450 条非定位输入的提示和目标 ID 不变；150 条定位输入的提示哈希和 GT 目标 ID 全部改变。量化差别如下：

| seed | 归一化提示增加 token | GT 目标平均增加 token | 教师目标平均增加 token |
|---|---:|---:|---:|
| 42 | +35 | +25.57 | +8.25 |
| 137 | +35 | +25.02 | +7.03 |

所有登记目标 ID 均以 248046 结尾，单目标≤128 token，输入加单目标≤2,048 token。这直接支持「组合干预」的审查结论。即使几何变换完全可逆，也不能把效果单独归给坐标单位或空间能力。复算没有重新运行 tokenizer，也未加载六个补实验的恢复状态。
