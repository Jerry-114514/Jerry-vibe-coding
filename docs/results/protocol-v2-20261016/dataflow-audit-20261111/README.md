第三批已独立加载 7B BF16 教师缓存，核对训练–评测图像指纹，重算排除候选近重复的敏感性，并复现修订 C 的全部六项分析，见[第三批证据](image-cache-and-revised-gate.md)。

本轮定位复算直接确认：**N 2,118/2,400 = 88.25%，U137 1,022/2,400 = 42.58%**。分三个数据来源，N 为 737、670、711 个命中，U137 为 359、330、333；各子集分母均为 800。U137 仅三条定位解析失败，不可能解释差距。此次复算没有重新生成 token，也没有重建环境或验证权重能否重新加载。

## 新发现：终止规则与格式效应应分轴报告

正式 v4.1 中有 **120 条非登记 EOS 结束**，全出自 N 基线的 MMStar（该轴的 8%）。它们在冻结计分下已经全错，改为「非 EOS 一律计错」后所有分数不变。没有发现定位非 EOS，因而这不是 U137 定位下降的原因；校准子集零截断不等于正式集零截断。若只对这 120 条改判正确，MMStar 基线理论最多升 8 pp；这是敏感性边界，不能当作另一种生成策略的实测值。必须另测固定回答模板和终止预算，才能区分基线推理不足与生成不合规。

N 的一致性有 173 条提示解析失败，U137 为零；N 的 MMStar 解析失败 139 条，U137 为 4 条。这些差异也可能改变对非定位收益的解释。现有正式分数按部署协议仍有效，但论文应同列解析率和答对率；不能把格式服从改善全解释为推理或语义一致性提高。若补充更宽松的解析，先登记语法、固定所有臂、报告主分数和敏感性分数，禁止按 GT 挑取答案。

## 公开论文与代码能借鉴什么

本轮公开检索从坐标编码、标准定位评测、跨轴指标、蒸馏监督四条线进行，优先采用原作者论文或实现。没有把不同模型/数据的分数直接拿来做本项目基线。

| 来源 | 可借鉴的实验或代码 | 在本项目的落点 |
|---|---|---|
| [Qwen 官方 grounding 实现](https://github.com/QwenLM/Qwen-MM-Plugins/blob/main/src/capabilities/api/qwen_mm_plugins_api/vl/grounding.py) | 同时保留归一化框与按原图宽高映射的像素框。该插件的模型与解析语法不等同于本项目冻结的 9B | 原始输出、原生框、原图框三列保留；直接映射作为独立校验；7B 仍按其显式处理器像素契约 |
| [Pix2Seq](https://arxiv.org/abs/2109.10852)及[作者代码](https://github.com/google-research/pix2seq)、[Hi-Token 预印本](https://arxiv.org/abs/2608.03471) | 定位可写成坐标序列生成；离散化及数字的轴/位值编码本身是模型设计变量 | 旧补实验不能称为纯几何干预。新一轮记录目标数字精度、序列长度及 token 分布，必要时另做同精度序列化对照；不把相对坐标本身写成创新 |
| [VLMEvalKit RefCOCO 实现](https://raw.githubusercontent.com/open-compass/VLMEvalKit/main/vlmeval/dataset/refcoco.py)、[MDETR 官方实现](https://github.com/ashkamath/mdetr) | RefCOCO 各版本与 split 分开报告；VLMEvalKit 输出逐题 IoU、命中和分 split 汇总 | 同时给出各来源样本量、Acc@0.5 和平均 IoU；额外区分逐题加权与 split 宏平均。对照实现自己的解析容错与标签定义，不能直接替换冻结 scorer |
| [POPE 作者代码](https://github.com/RUCAIBox/POPE)、[MMStar 作者代码](https://github.com/MMStar-Benchmark/MMStar/blob/main/README.md) | POPE 以二元对象探测构造测试；MMStar 区分带图/无图条件以审查视觉贡献 | POPE 建议补各负采样层、预测 yes 比例及混淆矩阵；另登记无图敏感性，不把 ScienceQA 或 MMMU 代理称为 MMStar，也不把项目内去重当作预训练无污染证明 |
| [Vision-Flan](https://arxiv.org/abs/2402.11690) | 分阶段利用人工标注任务与合成数据，讨论任务多样性和合成标签质量 | 先做同数据 GT-only，再做同种子、同批次、同表示的教师增量对照；统计教师与 GT 的差异和拒绝条目，不把模型大小当作教师质量的替代量 |
