# 独立路线 B：固定训练轴的 7B 自蒸馏实验

登记日期：2026-10-16。用户已授权本路线，原 ARP 阶段 C 保持未放行。历史报告中“尚未授权独立实验”的状态已被本次授权取代。

## 研究问题与边界

在固定 Qwen2.5-VL-7B 教师和同检查点学生、训练步数及优化器的条件下，比较 mmstar 代理训练、consistency 训练与四轴混合训练对四轴表现的影响。A1=mmstar，A2=consistency，U=四轴等比例，N=零更新。训练代理来源沿用已批准的训练池，不使用评测题训练。

这是固定轴干预与序列级自蒸馏的独立实验。它不验证阶段 C 的量尺反转，不验证量尺导致的选轴与资源分配后果，不提供跨代 API/本地阶梯的可合并性证据，也不证明 122B 教师的收益。未来 9B+122B 必须另立配置版本，不能沿用本轮结果冒称已运行。

本轮沿用 v1 的轴定义和本地 7B 教师，但依用户明确的“双 CE”标准，目标为 **0.5 真实答案 CE + 0.5 教师回答 CE**。旧 v1 的教师回答 CE+top50-tail KL 不是双 CE。本轮保存 top50 以备审计，但 KL 权重为零。学生使用已经通过 5090 预检的 BF16、语言层注意力+MLP 七类 LoRA，故本轮也不是旧 FP16/FP32 推理协议的数值复现。

## 固定预算、终点与停止规则

- 最小循环：seed42，从 3,545 条中按轴各取125提示，共500；一致性125提示实际104原题，其他各125原题。A1/A2/U各100次真实更新，N零更新。U的100更新每轴25次；单轴臂仅使用相应125提示。相同步数不等于相同独立原题或token暴露量，均单独报告。
- 最小评测：既有开发清单800提示、400原题，四轴各100原题，一致性保留五改写。N及三个适配器共3,200次生成；不解封独立确认集。
- 正式训练：三个训练臂×seed[42,137,256,512,1024]，每次1,000实际更新，共15,000。各臂固定600提示预算；U每轴150提示，循环训练时每轴250更新。一致性提示的相关性以原题/图像簇报告，不冒称600个独立单位。
- 正式评测：回4090，N一次加15适配器，既有16,900提示开发基准，共270,400生成。每轴配对N增量及A1/A2对U为主要比较；等权四轴均值为次要汇总。报告全部seed，后续区间以原题/来源图像簇配对重采样；本轮仍为开发性结果。
- 主要终点在固定步数读取最后检查点；不按评测表现选最佳步数、不追加seed。工程最小循环通过才进入15次训练。
- 非有限损失/梯度、零梯度、OOM、reserved>30GB、哈希变化、教师生成无EOS、任何长度超限、重复账本、剩余磁盘<5GiB即停；不静默截断、不把失败更新计入预算。训练管线8小时上限，按2.70元/小时折算21.60元；4090评测单列。

LoRA r16/alpha32/dropout0，AdamW lr1e-4、weight_decay0，micro-batch1、累积1，gradient checkpointing，梯度裁剪1，视觉上限1280、总序列2048、回答128 token。每50步保存适配器、优化器、CPU/CUDA RNG与元信息，原子写入恢复文件。

## 已启动的工程任务与验收

旧缓存3,545条已经CPU逐条核验SHA、top50形状/有限数值、输入/目标对齐、图片SHA及词表。没有回答文本触及128-token阈值，但旧缓存缺少原始生成结束原因，因此不能将此等同于严格无截断证明。原缓存不覆盖；独立新版本缓存用固定BF16/显式图像预算重新记录原始生成ID、EOS和top50。该版本的logits不可与旧精度缓存混用。

独立执行器为 `tools/route_b_experiment.py`，不修改旧训练器或旧gate。已在新5090后台启动教师缓存；训练器和CPU审计/报告工具并行开发核验。同一张GPU上的教师推理、训练和评测由项目锁串行。

| 五项验收 | 真实检查方式 |
|---|---|
| 缓存加载、无截断 | 新缓存全部3,545条覆盖，原始生成以EOS结束，输入/目标边界一致，实际训练前验证逐文件SHA |
| 双CE有限、梯度非零 | A1/A2/U各100连续实际更新；逐步写GT-CE、教师CE、合成损失与裁剪前梯度范数 |
| 适配器保存/加载 | 导出张量与内存适配器逐张量相等；新评测进程实际从磁盘重载完成推理 |
| 四轴评测 | 每臂800提示精确覆盖；按原题合并一致性五改写，输出四个独立分数 |
| 中断恢复 | A1第50步退出子进程，新进程恢复优化器与CPU/CUDA RNG至50，再写51–100；记录恢复后首损失、步数连续性及PID |

报告另列四轴各125提示的question、视觉、完整prompt、GT回答、教师回答及两路总长度的min/max/mean，避免把纯文本token数当作视觉模型训练成本。

## 时间与费用估算

单价采用用户指定 **2.70元/小时**。旧5090完整双CE预检实测约0.532–0.571秒/步；这只是当前新数据分布的先验估计。

| 内容 | GPU时间计划 | 5090折算费用 |
|---|---:|---:|
| 全量3,545条新EOS证据缓存 | 15–35分钟；早期360条均值0.248秒/条，后续定位/长回答可能更慢 | 0.68–1.58元 |
| 最小三臂300次更新、加载及真实恢复测试 | 5–12分钟 | 0.23–0.54元 |
| 最小四臂3,200提示评测、验收及备份 | 15–30分钟 | 0.68–1.35元 |
| 最小循环合计，含全量缓存 | **35–80分钟** | **1.58–3.60元** |
| 15次正式训练，含加载/保存 | 3–4小时 | 8.10–10.80元 |

旧7B开发评测800提示均值约0.245秒/提示。正式270,400提示仅按此吞吐折算为18.4小时，计划20–30小时4090评测；复杂回答/单轴适配器可能拉长，首100条再更新ETA。4090时价未提供，费用为20–30×实际4090小时价，不擅用5090价格。全流程还应计入备份/等待的开机时间；如果实际购买的是64.77元包日，账单以套餐为准，不承诺按小时退费。

## 存储和论文措辞

源代码、预登记与精简结果表进入仓库；远程教师缓存、损失/显存日志、恢复状态、适配器、逐题评测和SHA清单进入GitHub Release，保留每臂完成后的增量备份。本机仅保存代码和小型报告。正式训练完毕仍应标记“4090评测待完成”，不得将15个完成标记等同于全实验完成。

可用于论文的方法措辞：

> 我们另行开展固定训练轴的序列级自蒸馏实验，以相同Qwen2.5-VL-7B检查点作为教师与学生，结合真实答案和教师回答的交叉熵监督，比较推理代理、一致性和四轴混合训练在固定更新预算下的收益及负迁移。训练轴在观察本轮训练结果前固定。本实验独立于ARP阶段C的门槛判定；结果不用于证明量尺反转、由量尺诱发的选轴因果效应，或本地与商业API阶梯的可拼接性。评测使用已有开发基准，推断范围据此限定。
