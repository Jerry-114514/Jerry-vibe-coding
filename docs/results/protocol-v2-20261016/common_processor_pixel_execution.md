# 7B/9B统一处理器像素测量：当前执行协议

2026-10-17。用户明确批准：不重训，统一定位坐标契约，复测7B的全部16模型。此页替代此前尚未生成新预测的0–1000队列；旧协议、CPU诊断与原始输出均保留，不覆盖。

## 共同契约

对每个模型使用其冻结处理器实际编码的宽高，提示明确要求输出该尺寸下的像素框。原始文本、处理器像素框和原图像素框分别保存：

`x_original = x_processor × original_width / processor_width`

`y_original = y_processor × original_height / processor_height`

统一与原图标注计算IoU≥0.5。每次推理断言实际`image_grid_thw`等于CPU冻结网格；不按答案、训练臂或分数选择坐标单位，不将旧千分比框直接当作像素。非法、越界、非有限或含额外说明的框按固定解析器处理，禁止自动切换另一坐标系补分。

7B与9B共用同一个`processor_pixel_contract.py`。统一的是换算规则，两代实际分辨率、patch大小和视觉处理器仍可不同，不能因此声称跨模型所有混杂均已消除。训练目标及预算保持原样，原ARP阶段C仍未放行。

## 执行顺序与时间

1. 9B按原15次训练队列收尾，原12小时训练绝对预算不重置。
2. 核验15份训练日志及本地/Release恢复可用性，跑9B共同契约校准。低于固定门槛即停，不为提高分数调提示或重复抽样。
3. 跑7B共同契约定位复测：N前100条先校准，之后补完N及15适配器。逐模型核对2400唯一ID、冻结清单、原始输出重评分及哈希，压缩并经Release服务端SHA核验后继续下一模型。
4. 7B复测完整交付后，才启动9B的16模型全量评测；其40小时绝对预算在这里开始，不把等待7B的时间伪装为已运行正式评测。
5. 7B单轴4项区间及9B四轴12项区间分开报告。原7B旧12项检验保留为旧提示/旧计分结果，不混称同一次事前检验。

7B旧定位时延外推本次纯生成约6.47小时、约17.47元（2.70元/小时）；加入装载、校验及上传暂估6–8小时，新提示的实际长度可能改变耗时。12小时上限对应32.40元，不按结果临时追加预算。它增加了先前9B计划的等待时间；若校准通过且网络正常，整体预计10月19日上午完成，届时按新实测更新。
