## 固定比较规则

- 对 Qwen2.5-VL 3B、7B 分别比较旧 v1 同一完整题集上的四轴分数，共八项差值。
- 每项 abs(API - local) 必须严格小于 0.005，即 0.5 个百分点；等于阈值不通过，不用八项平均值抵消大偏差。
- 核对精确模型身份、输入图片、题目 ID、问题模板、输出上限、解析协议和聚合方式。五改写归为同一原题，报告共享来源图像簇的配对区间；不把区间跨零解释成等价。
- 旧 v1 实际是语言 FP16、Qwen 视觉 FP32，原因是已验证的 FP16 视觉溢出；必须照实记录。API 内部精度未披露，因此这属于部署一致性检验，不能单独归因于精度。
- 此前 precision-bridge/ 下的 BF16 开发预检不属于同检查点 API 桥接。qwen3-vl-plus、122B 和 397B 均不能替代精确 3B/7B。
