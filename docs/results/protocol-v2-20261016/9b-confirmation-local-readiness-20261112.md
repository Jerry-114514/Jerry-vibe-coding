# 9B 确认实验本地准备记录

2026-11-12（北京时间）。状态为等待两份人工盲审回执。未冻结正式确认清单，未启动 GPU 训练。

- 定位排定五层，每层 48 道主样本和 12 道备用题。300 道对应 300 个不同图像组件。每张图像已核对文件 SHA256、解码 RGB 哈希和尺寸。盲审包 SHA256 为 `e554c0924aed0bd05abc68ab6fe474af57b1bac1a49bb2f147bad893bd947bba`。
- 次要三轴各 120 道原题，分别包含 114、88、119 个图像组件。已从 Release 分卷流式恢复 321 个图像文件，核对文件 SHA256 和 RGB 哈希。未将分卷整体保存到本机。
- GT-only 训练的预分词计划有 600 条训练样本，每轴 150 条。8 个新 seed 的每对共享同一顺序，每臂每轴 250 步。训练图像与包含备用题的评测图像之间，基于归档指纹复核得到精确 RGB 重叠 0、dHash 距离不超过 4 的对数 0。像素目标与归一化目标回转误差上限为 0.0032 像素。训练计划 SHA256 为 `2e18bd0e8c01852dd28605a560a92cc2543502e21eb9ca879500af9dbc7b2dfe`。实际 tokenizer 对齐和显存预检待执行。
- 计分器回放历史基线 960 条，959 条判分一致，唯一差异来自旧定位输出的 `bbox_2d` 对象包装。新协议要求严格的四数 JSON 数组。像素/归一化的同框对照、EOS 截断、无效框和缺行测试均通过。预演精度区间半宽约 6.6–10.6 pp，取决于假设的配对错判率与 seed 波动。240 道可用于检验旧实验量级，接近 +5 pp 的效应仍可能不确定。
- 盲审收件规则已在收到结果前登记。两份回执必须覆盖同一批 300 题。每道题须由两位审阅者都判为可用，两框互相以及各自与源 GT 的 IoU 均至少 0.5。歧义或分歧记录后排除，同层按预定顺序从备用题补足。任何一层少于 48 道即不产出正式确认清单。保留源 GT，分析不看审阅者身份。回执、盲审 ID 映射及候选标签保留在本地。
