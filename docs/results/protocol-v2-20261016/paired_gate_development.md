# 配对量尺与噪声分析：开发验证

2026-10-16 16:45 完成。三个家族各做四轴及去除定位轴两种分析，共六组；每组 1,000 次外层、128 次内层图像簇重采样。完整逐次分布已从 AutoDL 上传本阶段 GitHub Release，本地仅保存小型摘要。

## 与旧分析的实质区别

在同一次外层图像簇重采样中重新计算 F_scale，并从这个外层经验分布进行内层重采样计算 F_noise，再逐次计算差值。没有把旧的两个独立 Bootstrap 数组逐项相减。

同一图像的计数在全部模型、底线答题器和轴之间共享；按图像的跨轴/跨子集成员模式分层，保留每个成员模式的图像簇数。所有结果先在各子集内计算，再对轴内子集等权。噪声参考尺固定为未校正的绝对差、各相邻边等权、解析失败记错；一致性五改写仍为一个原题单元。

冻结开发判据要求：至少 80% 结构类有效、至少 95% 外层差值可定义、配对 F 差值 95% 区间下界大于 0.05、配对严格反转差值区间下界大于零，且点估计严格反转比例至少 0.05。这里的协议用于估计量工程验证；旧数据已被观察，不能称为新的确认性预注册，更不授予正式训练许可。

## 结果及训练判定

| 家族，四轴 | 严格反转比例 | 点估计有效结构类 | 可定义外层差值比例 | 判定 |
|---|---:|---:|---:|---|
| Qwen | 0 | 12/12 | 61.8% | indeterminate，不放行 |
| InternVL | 0.4，仅对有效少量类 | 5/60 | 0 | indeterminate，不放行 |
| LLaVA | 1.0，仅对有效少量类 | 2/12 | 0 | indeterminate，不放行 |

Qwen 的 F_scale 点估计为 0.25，F_noise 为 0.015625。符合定义域要求的配对 F 差值区间约 `[0.00083, 0.25]`，但仅 61.8% 外层重采样满足差值定义域，不能把筛选后的正区间当成总体显著性；严格反转点估计及全部外层分布均为零。

InternVL/LLaVA 在极少有效结构类上存在不同选择，但绝大部分结构类不能进入共同四轴域，不能把条件翻转率当成完整证据。去掉定位轴后有效比例均为 75%，仍低于冻结的 80% 门槛。六组分析均为 indeterminate。

这一结果进一步说明：需要修复测量协议、准备新审计/确认数据；不能为了让 GPU 忙碌而绕过 C 开始正式多种子训练。
