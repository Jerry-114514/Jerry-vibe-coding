# 9B 独立正式实验：固定15次调度已登记，尚未训练

已按用户的9B接力要求准备正式控制器。当前7B完整评测继续；9B基础设施GPU推理烟测已通过，训练/评测输入准备在CPU完成，GPU训练尚未开始。正式控制器已实际存活并等待最小循环的五项真实验收，不能把排队登记视为实验完成。

## 训练前登记与强制门槛

[固定正式计划](9b-formal-plan.json)与[GitHub登记收据](9b-formal-registration-delivery.json)已生成，均早于9B学生的最小循环结果。15个逐臂训练清单在AutoDL生成并直接归档到9B Release，本机仅同步其SHA256。

训练臂A1=mmstar代理、A2=consistency、U=四轴等比例；seed固定42/137/256/512/1024；每次1,000次实际提交更新，共15,000。每臂600提示，U每轴150提示、1,000步中每轴250更新。N不训练，只有一个未更新基线。

完整顺序为：7B全部16模型评测与原分析完成→9B完整配置显存预检准入→500提示最小循环五项验收→15次正式训练→N和15适配器完整评测。正式控制器在启动前独立重跑最小循环验收，并将验收SHA256绑定到正式启动证明。没有按分数提前结束、选最佳检查点或追加seed的分支。

训练阶段12小时、评测阶段40小时上限分别写入绝对UTC预算文件，重启不刷新额度。已完成任务跳过而不重跑；未完成任务从相应检查点恢复。若JSONL末尾只有未写完的一行，先另存尾段，再保留完整记录；训练检查点之外的未提交更新由冻结执行器另存后回退，最终轨迹仍固定1,000提交更新，重算成本受原时限约束。

## 磁盘与恢复状态

下文代码中的local以及脚本报告里的“本机”均指AutoDL实例，用户Windows电脑不下载恢复状态或大模型权重。

当前数据盘空闲约12GiB，直接额外保留15份优化器会挤占后续空间。采用以下可恢复的归档规则，**不改动7B任何恢复状态**：

1. 每次训练完成后，独立检查连续步数、冻结采样、双CE/梯度、优化器内部步数、CPU/CUDA/Python RNG和适配器张量一致性，记录真实恢复文件SHA256。
2. 整个该臂目录直接上传GitHub Release；保存不可覆盖的`training-delivery.json`和`training-inventory.json`。再次读取GitHub资产元数据，核对服务器大小、SHA256，以及清单中该恢复文件的SHA256。
3. 只有这些检查都通过，才写入`resume-offloaded.json`恢复指针，然后清理**AutoDL上已完成任务的优化器副本**。适配器继续留在AutoDL用于评测；恢复状态原件仍在GitHub归档中，指针记录资产、归档内路径和解包后的SHA256。进行中任务的恢复文件始终留在AutoDL。
4. 最小循环的恢复状态只有在全套验收和归档完成后，才可按相同规则腾挪。源文件或服务器摘要不符时绝不清理AutoDL上的恢复文件。后续评测只上传元数据增量，不重复打包已存的适配器/优化器。

六项控制与统计测试已通过：服务器失败保留本机状态、归档成员摘要不符保留状态、成功归档后保留适配器与恢复指针、残缺尾段保全、时限不重置，以及16模型统计中相同两臂的配对差恒为零。前两类使用合成文件和模拟服务器，不冒充真实9B训练验收；服务器读取路径另用现有登记资产做了实际只读验证。

## 评测、报告与范围

15次训练完成即生成逐次损失/显存/步耗时表和曲线，并归档；随后每次只评测一个适配器，不加载优化器、不保留梯度。每模型16,900提示、16模型共270,400提示，逐题重评分、精确覆盖和四轴汇总必须一致。

最终报告列出全部16模型四轴分数，以及A1-A2、A1-U、A1-N的配对区间。按5个训练seed和来源图像簇配对重采样10,000次；12项比较以Bonferroni给出名义近似95%整体区间，同时保留逐项区间和有限seed/尾部分位数局限。

这是独立9B+122B扩展，原ARP阶段C仍未放行。与7B自蒸馏同时改变学生、教师、预处理和可用池，不把差异单独归因于模型容量。最终目标验收还需新鲜核对全部必要GitHub资产，不能只看本机的完成标记。

独立交付核验工具为`tools/audit_9b_student_delivery.py`。它汇合教师、预检、最小循环、正式训练和评测的归档清单，重新检查实际服务端大小及SHA256；恢复文件已归档腾挪时，还须验证本地首次张量验收记录、不可变交付回执、清单、精确字节数和恢复指针。工具不执行训练，不修改四个冻结数值源文件；覆盖核验通过也不能代替独立科学/内容验收。当前9B训练尚未开始，其交付核验应返回未完成。四个合成存储测试验证路径映射边界、已知登记文件映射、缺失归档/篡改回执不能冒充恢复状态已交付，以及原始HTTP请求/响应为必需证据但归档回执不递归要求保存自身。
