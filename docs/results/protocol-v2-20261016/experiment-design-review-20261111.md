# ARP 与 7B/9B 蒸馏实验设计复审

日期：2026-11-11。审查范围：原 B/C/D、7B 自蒸馏、9B API 教师序列蒸馏、定位 2×2 补实验、下一轮 16 次训练方案。依据是已保存的协议、代码、逐题审计和统计产物；本次未重跑模型，也未改动历史结果。

## 结论

**有设计问题，并且至少有一个已实证改变了结论：定位评测的坐标契约不一致，使 7B 的一项训练对照发生方向翻转。** 9B 修复解析和 EOS 后仍有真实的逐题表现下降，但现有补实验只能把原因缩小到「训练输出契约及其与统一推理口径的适配」这一组因素，不能单独归因于坐标标签、教师质量或视觉能力退化。

结果并非全盘不理想。9B 的 A1 相比零更新基线，一致性约 **+5.05 个百分点**，该预登记对比的校正区间不跨零。U 臂在推理和一致性上有描述性收益，却伴随定位代价。与其扩大模型或重跑全部历史组合，更有价值的是先验证这种代价能否通过训练契约匹配稳定避免。

## 已核实的设计问题

| 严重度 | 问题 | 证据与影响 |
|---|---|---|
| 高 | **历史定位口径混入输出格式** | 7B 的 A1−U 定位差由旧口径约 −11.53 pp 变为处理器像素复测的 +3.32 pp。权重没改，方向改变来自测量。旧定位值适合保留为审计证据，不适合作为能力结论。9B 旧最小循环的近零定位及后续 EOS 截断也不应与 v4.1 正式分数混算。 |
| 高 | **9B 补实验同时改了训练提示与目标字符串** | [训练编解码器](../../../tools/repair_9b_codec.py) 对 N-* 调用 [native_prompt](../../../tools/qwen35_native_frontend.py)：移除原图像素和长宽提示，加入 0–1000 说明、全图示例和 JSON 指令；再换算 GT 与教师坐标，用 JSON 序列化浮点值。单位、提示信息、数值精度和 token 长度共同改变。统一用原生归一化提示评测是合理的部署比较，但只测一种推理契约，无法分辨几何能力和格式迁移。**旧补实验的因素应改称「训练坐标契约」，不能写成只改标签。** |
| 高 | **训练臂比较不能识别蒸馏的增量贡献** | 7B/9B 主要训练臂均为 GT CE 与教师 CE 混合，N 不更新。对 N 的收益包含任务监督、训练数据和教师目标，缺少与同一臂同样本的 GT-only 主对照。7B 缓存有 top-50 logits 但此轮 KL 权重为零，不能归功于 KL。补实验 GT-only 和双 CE 步数匹配，但双 CE 两次前向，计算量不同；教师对定位的旧区间跨零，既不能证明有效，也不能证明有害。 |
| 中高 | **同更新数不等于同曝光或同任务** | A1 使用 ScienceQA 代理，评测是 MMStar；保留集又是 MMMU 单图选择题代理。A2 的多改写共享原题或图片，U 各轴各 250 次更新；单轴臂的对应轴有 1,000 次。比较体现训练配方效果，但混合了任务分布、独立图像量、重复率、答案 token 数和分轴剂量。A1 没显著提升 MMStar，不能据此证明推理训练普遍无效。 |
| 中高 | **补实验的有效训练样本只有两个 seed** | 旧 P-D 使用历史端点；seed 137 是观察到异常后重点诊断的端点。保留集可以检验题目迁移，不能替代新训练 seed。10,000 次 bootstrap 不会创造更多训练重复；24 项校正的每个尾部约 10 次抽样。现有区间宜作探索性证据，不能视为稳定的确认结果。 |
| 中 | **原 ARP 的科学准入没有通过** | [修订门槛复核](paired_gate_development.md)中，Qwen 严格反转率为零，只有 61.8% 外层重采样定义了所需差值。筛选后的区间不能证明总体量尺效应。跨代、跨教师、跨精度和输出契约的 7B/9B 独立实验也不能补齐同检查点精度桥接或支持纯容量归因。 |

## 对 42.58% 的判断：明显低分，但不是单点故障

原 v4.1 正式口径下，U 的五个 seed 定位均低于未训练基线 88.25%，均值约 67.34%；**即使描述性地去掉最低的 seed137，其余四个均值约 73.53%，仍低 14.72 pp**。这是敏感性检查，不是剔除 seed 后重新给出显著性。原登记的 12 项比较不含 U−N，不能把上述均值差当成登记检验通过。

U137 仅 3/2,400 条解析失败、没有长度截断，中位 IoU 约 0.438；按两套预定义像素解释重算也无法恢复。其训练步数、恢复状态、输出行数以及梯度有限性都通过已有核验。现有证据排除了「单纯漏解析」和「训练中途异常退出」作为主要解释；不能排除样本顺序、梯度干扰或优化超参数的问题。12 张匿名抽样里可见对象选错和框范围偏差，但不是双人盲审，不能推断错误类型的总体比例。

用[补实验原始统计](9b-repair-final/report/results.json)重算每个 seed 的定位差（归一化训练契约减像素训练契约，pp）：

| 数据集 | GT-only，seed42 | GT-only，seed137 | 双 CE，seed42 | 双 CE，seed137 |
|---|---:|---:|---:|---:|
| 开发集 | +17.88 | +20.54 | +5.58 | +47.00 |
| 旧保留集 | +20.83 | +14.17 | +5.00 | +47.50 |

GT-only 的两个 seed 都有同向改善，因此「必须有坏教师才会出问题」不是成立的必要条件。双 CE 的大差异则主要来自 seed137，其机制不可直接推广。旧保留集的 GT-only 均值为 +17.50 pp；此前常引用的 +21.875 pp 是两类监督平均的**因素主效应**，不是下一轮 GT-only 的已验证效应大小。

## 租卡前应修订的下一轮方案

**保留 16 次训练，先把研究问题改准。** 主问题定义为：固定 9B 学生、GT-only、U 数据和部署评测口径时，匹配原生归一化的训练契约能否在新 seed 与新确认图像上改善定位？这是一项可复现的部署对照，不宣称「只改坐标标签」。[原续实验方案](experiment-resumption-plan-20261111.md)里「只转换定位标签」不能与原编解码器直接同时成立，本复审给出冻结前的修订。

1. **明确两种训练契约。** 两臂使用同一批原题与图像、相同 JSON 输出要求和尽量对称的提示模板，只保留单位定义所需的差别；记录模板 SHA、提示和目标 token 分布、数值精度及可逆误差。在训练前验证样本 ID、图像张量规格、非定位样本和更新顺序逐对一致。若使用旧模板做原样复现，明确登记它是含示例、长宽信息和数值格式在内的组合干预。不要给模型一个要求输出像素的提示却监督归一化答案，或反过来。
2. **用交叉评测区分可用性和迁移。** 同一批冻结定位图像，对所有适配器及基础模型分别跑预定义的原图像素与归一化推理提示。每种提示用固定对应解析器；统一转回原图计算 IoU。主终点仍是归一化部署口径下 N-G−P-G；像素口径及训练契约×推理契约交互作预登记的机制分析。若优势随提示反转，说明格式匹配贡献较大；若在两种口径都同向，才有理由进一步验证几何质量。补报解析率、IoU 分布和阈值敏感性；不要把仅在可解析预测上的条件 IoU 当作主结果。
3. **把 seed 和样本抽取拆开。** 先冻结一份 U 训练样本池用于所有新 seed；同一 seed 的两臂使用同一 LoRA 初始状态与样本顺序，不同 seed 可改变初始化和顺序。主结论限定在固定样本池和独立确认图像。若之后要推广到训练数据抽样，再独立增加样本池重复，避免将训练集变化误当成优化随机性。
4. **冻结统计边界。** 8 个新 seed、两臂各 1,000 步；新确认集在看新模型输出前完成历史曝光、近重复和图像簇核查。先用旧逐题账本和预设差值场景评估精度需求，不能把 120 道定位题直接当成 120 张独立图像。登记最小有实际意义的增益、主要对比与次要比较族；以 seed 作训练重复、以图像簇表征题目不确定性。基础模型仅一个端点。预先明确符号翻转的可交换/对称条件、无效输出处理及缺失配对处理。
5. **区分改善与修复。** 若 N-G 优于 P-G，只能说相对像素训练更好。要称为「恢复到不训练的水平」，需提前设定相对基础模型的非劣界限并通过检验；要称为「提升基础能力」，则需独立证据和盲审。若主比较结果不确定，保留区间和所有 seed，不能事后改变主终点。

交叉评测只新增一个定位提示版本（若 120 道定位题，17 个端点约 2,040 次额外生成），**无需增加训练次数或显存档位**；顺序评测即可。沿用 32 GB 5090 的 100 步预检及全卡余量验收。后续若要分离教师干扰，才补同 seed 同配方的双 CE 两臂；若要区分监督表示与数字 token 长度，另登记控制精度/序列化的对照。现在不建议先上更大模型。

论文可以保留「坐标契约会改变我们对训练收益的判断」作为有实证支撑的主线；将「教师造成能力退化」「归一化纯粹提高定位能力」和「原 ARP 已成立」留作未证实命题。
