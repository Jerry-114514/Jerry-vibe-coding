# 9B 配对训练运行入口验证

2026-11-12（北京时间）。本地 CPU 验证完成。未收到人工盲审回执，正式确认集待冻结，未租卡。

- 两臂使用同一份 100 步预检顺序，包含训练池内最长输入和最大视觉网格。8 个正式 seed 的两臂分别按同一个 1,000 步序列执行，每轴 250 步。启动时校验计划、样本和实际 token 哈希，并比较配对的初始 LoRA 权重哈希。
- 训练入口复用既有 BF16 语言层 LoRA 配置，使用 GT 单 CE。每 50 步原子保存权重、优化器、随机状态和已提交损失日志哈希。恢复时保留但回退未提交的更新行；终点导出适配器并逐张量核对。正式模式要求真实盲审清单和双臂训练预检凭证。
- 18 项相关测试通过。中断夹具模拟 53 次更新后退出，从第 50 步检查点恢复，并验证保留第 51–53 步的未提交记录和半写尾行。正式模型、优化器恢复和显存尚未在 CUDA 上执行。
- 600 条训练样本引用 578 个图像路径，选定文件共 66,764,143 字节。归档映射和样本 SHA256 已对齐。待新实例部署时只恢复选定成员。定位和次要轴评测图像此前已在本机核验。
