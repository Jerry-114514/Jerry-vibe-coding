4. 用户明确授权独立v4.1及新900秒预算；生成与finish_reason统一显式EOS集合`[248046,248044]`，保留原序列结束符。提示、坐标、解析器、样本、128-token上限、权重和训练未变。
5. 新协议先上传并核验，再做真实400条GPU校准。A1-seed512真实重跑17/20正确、零解析失败/截断；全16模型均零解析失败/截断。新400条计入后续270,400总量，旧340条失败输出不混入新协议。
