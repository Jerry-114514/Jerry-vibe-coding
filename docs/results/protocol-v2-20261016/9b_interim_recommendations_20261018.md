# 当前结果的分析建议与后续对照方案

日期：2026-10-18。依据：7B最终定位复测，以及9B v4.1已完成的N、A2-seed42端点。仅探索性中期诊断，不改变正在运行的16模型评测、原计分、检查点、数据、预算或12项比较族，不启动新训练/API调用。

## 最重要的观察：增益与格式有效性强相关

A2-seed42对N的四轴点差为POPE +0.533pp、定位 +0.542pp、一致性 +6.750pp、MMStar +4.533pp。单seed不能宣布显著提升。

对完整账本逐一验证SHA、按原题配对。有效定义为该原题所有提示均可解析且以EOS结束；一致性仍按冻结规则将五改写合并、五次全部答对才计1。没有删掉任何正式评测题。

| 轴 | 原题数 | 总分点差pp | 双方均有效题的净变化对总分贡献pp | N无效→A2有效题的净变化对总分贡献pp |
|---|---:|---:|---:|---:|
| POPE | 9,000 | +0.533 | +0.533 | 0 |
| 定位 | 2,400 | +0.542 | +0.542 | 0 |
| 一致性 | 800 | +6.750 | +0.500 | +6.250 |
| MMStar | 1,500 | +4.533 | -0.267 | +4.800 |

一致性：740道双方均有效原题中净增4题；60道N无效而A2有效原题中净增50题，总净增54题。MMStar：1,360道双方均有效题中净减4题；139道N无效而A2有效题中净增72题，另1道N有效而A2无效题净变化0，总净增68题。

这是基于输出有效性分组的描述性恒等拆分。**不能把这些组的差值视为格式修复的因果效应**：组别取决于模型输出，存在选择问题；“N无效→A2有效”同时可能包含格式遵循与知识变化。它提示优先检查答案输出稳定性，不能据此宣称已测得纯推理增益或纯格式效应。有效性条件分数始终作为附录诊断，主表继续以全部题为分母。

## 立即做：不新增GPU或API预算

1. 跑完已锁定16端点评测，所有seed及失败题都保留。保持五seed、10,000次配对seed/图像簇bootstrap和12项Bonferroni主分析；不按中期结果提前停、选seed或追加训练。
2. 全量结束后对各臂全部seed生成“主准确率、解析失败、长度截断、输出token分布、共同有效题诊断”并排表，沿用同一离线分组规则，不按结果挑有利阈值。副分析明确为看过结果后的探索性，不混入原12项确认口径。
3. 将一致性拆成每改写答题准确率、五改写全部答对率、有效输出内答案一致率。不能把五次答同一个错误答案计作知识正确，也不能把当前全部答对率简单称为纯一致性能力。
4. 对U-seed137及其他seed按数据集、题长、图像尺寸、解析/截断分类排错，保留离群值；同时展示五seed散点、均值、配对区间，不只画均值柱状图。
5. 审计训练池：每臂不同原题/图像数、重复曝光次数、监督token总量、答案长度、教师与GT一致/不一致比例。等1,000步不自动等token、等独立样本或等轴内曝光；主实验保持不变，将这些差异作为预算解释。

## 下一轮优先对照：另行注册和预算后才执行

| 优先级 | 对照 | 回答的问题 | 设计约束 |
|---|---|---|---|
| 最高 | 同9B、同数据、同臂的GT-only SFT | 收益是否需要122B教师，而非普通监督微调即可获得 | 同seed/更新数/LoRA/输入/评测；明确CE归一化，去掉教师项后避免无意减半梯度规模 |
| 高 | 仅输出结构/EOS监督的格式对照 | 格式规范化能解释多少接口收益 | 屏蔽语义答案token，只监督结构和结束标记；仍不能假定完全隔离语义效应，需实测 |
| 高 | 新冻结的未见题/图像确认集 | 开发集上出现的提升能否外推 | 与训练/已见校准按图像及近重复隔离；先定方案再看结果，不替换当前主表 |
| 次高 | token预算匹配及曝光匹配对照 | 单轴/混合轴差异是否来自监督量或重复采样 | 在新协议中明确同时控制哪些量，不能假装步数、token和独立样本三者天然等价 |
| 条件性 | A1短推理依据+最终答案蒸馏 | 若答案级蒸馏没有推理增益，过程监督是否更有效 | 先审计当前教师是否仅给答案；使用独立训练集和预算，不使用评测答案生成训练样本 |

优先级最高的是GT-only对照。原有N只能回答“更新与不更新”，不能单独证明增益来自教师知识。若训练目标中教师答案与GT大量一致，双CE可能主要在相同监督上加权；一致率必须按实际池核验，不能先假设。

序列级蒸馏使用教师生成序列做监督，与需要教师完整分布的token级KL应区别报告。参考[Kim与Rush，EMNLP 2016](https://aclanthology.org/D16-1139/)。后续若考虑推理依据监督，可借鉴[Distilling Step-by-Step，ACL 2023](https://aclanthology.org/2023.findings-acl.507/)，但它不能保证本9B视觉任务获益。

上述新对照暂不执行，也不消耗现有正式评测预算。若最终要作跨seed结论，新增对照应覆盖相同五seed；单seed工程预跑不能替代最终推断。

## 论文如何写

当前更稳妥的问题是“轴向监督与序列蒸馏如何改变端到端任务表现及输出可靠性”，而非先宣称122B教师增强了学生推理。7B定位旧优势在修订计分后不稳健，9B又显示格式有效性对分数的明显影响，两者共同支持将测量校准与错误分解单列成节，但不证明所有收益或退化都来自格式。

最终主结果按锁定口径报告；格式/截断拆分为探索性机制诊断；GT-only等新对照为下一轮研究。原ARP阶段C未放行，7B与9B同时改变学生、教师、训练池及接口，不能据此做纯容量或ARP因果归因。
